# 班主任工作台（中学）

面向中学班主任的班级管理工作台网页应用，第一阶段包含：**整体框架 + 工作台首页 + 座次表 + 数据持久化与编辑**。

## 运行方式

直接用浏览器打开 `index.html` 即可（无需安装依赖、无需联网），或任意静态服务器托管：

```bash
python -m http.server 8080
```

## 已实现功能

- **整体布局**：左侧固定导航（8 个菜单项），右侧主内容区；浅绿 / 浅蓝 / 米白配色；平板适配，侧栏可折叠（桌面端）或抽屉式滑出（窄屏）。
- **工作台首页**：常规工作（早读考勤 / 课堂纪律 / 作业收缴 / 课间巡查）与特色工作（主题班会 / 家校沟通 / 学生成长 / 班级活动）两大板块，共 8 张卡片，点击弹出详情面板。
- **座次表**：默认 6 排 × 8 列座位图，**排 / 列可在编辑模式随时调整**（1-12 排 × 1-16 列，超出范围的学生自动转未安排）；支持按 8 个小组多选高亮、按姓名模糊搜索定位（含拼音：如输入 z / zhang / zmx 可匹配张同学）；「编辑模式」下可修改学生信息、新增学生、删除学生、移除座位、移动 / 互换座位，未安排座位的学生会进入待安排面板。
- **数据持久化**：全部数据存入浏览器内置的 IndexedDB（零安装、无需服务器），首次打开自动播种示例班级数据；顶栏提供「导出数据 / 导入数据」做 JSON 备份与恢复。
- **初始化向导**：首次打开先进入三步向导——填写老师姓名 / 班级名称 / 学期，再选择初始数据来源（导入花名册、示例班级数据或空白开始），最后确认进入工作台；之后可随时在顶栏「设置」修改老师与班级信息。
- **花名册导入**：支持 CSV 花名册（姓名、性别、小组、排、列、班委职务、家长姓名、联系电话）或本应用导出的 JSON 备份，向导内可下载 CSV 模板。
- **课程表**：周一至周五 ×（早读 + 8 节课）完整课程表，展示任课教师信息与调课记录；「编辑模式」下点击课程格可修改科目与教师（任课教师自动同步），可添加 / 删除调课记录；支持 CSV / Excel / JSON 导入（含模板下载、解析预览）与 CSV / Excel 导出。
- **导入中心**：顶栏「导入数据」提供三类导入——JSON 备份整体恢复、花名册（CSV / Excel，替换学生名单）、课程表（CSV / Excel，合并教师与调课记录）。均支持解析预览与模板下载（CSV 模板 + Excel 模板，见 `assets/templates/`），Excel 文件可在浏览器内直接解析，无需安装任何软件。
- **导出中心**：顶栏「导出数据」提供花名册、课程表、完整备份三类导出；花名册与课程表可选择 **CSV 或 Excel** 格式（Excel 由浏览器内置生成器实时生成，真实 .xlsx 文件，Excel / WPS 可直接打开），完整备份为 JSON（含全部数据，用于恢复）。
- **待办事项**：首页「待办提醒」支持新增、编辑、删除、勾选完成，可设截止日期与优先级（高 / 中 / 低），逾期自动红色高亮；数据随备份一起保存。
- **早读点名**：考勤面板提供「开始今日点名」——48 名学生逐一循环切换 到 / 迟到 / 请假 / 缺勤，支持「全部到」一键复位，实时汇总异常人数；保存后自动生成迟到 / 请假 / 缺勤名单并重算出勤统计，逐人状态随备份一起保存。
- **今日课程**：首页欢迎栏「今日课程」按当前星期几从课程表实时取数（不再是写死的节数），点击或悬浮弹出当日课程列表（含早读与空课），当前老师（班级设置中的老师姓名）所教课程会高亮标出，并可一键跳转完整课程表。
- **花名册**：学生档案表格（学籍号 / 姓名 / 性别 / 小组 / 座位 / 班委职务 / 家长 / 电话），支持按姓名 / 学籍号 / 家长 / 电话**模糊搜索（含拼音）**、按小组与未安排筛选，统计栏展示人数构成；可新增 / 编辑 / 删除学生，点击行查看档案，**联系电话可一键复制**，一键导出 CSV / Excel。
- **成绩分析**：多场考试管理（新建 / 删除 / 编辑录入 / CSV·Excel 导入导出），单科与总分统计（平均分 / 最高最低 / 及格率 / 优秀率 / 参考人数）、分数分布图、排名表（含与上次考试的进退步对比、按小组筛选）；点击学生查看个人成绩档案（各科得分与班均对比、总分、名次、均衡指数）。
- **值日表**：按周自动轮值排班（每天 6 人、任务自动轮换、每周轮转），周次切换与「自动排班」；每日打卡（完成状态 + 备注，可撤销）；编辑模式可调整任一天的值日名单；「复制本周值日表」一键生成可粘贴到班级群的文本。
- **班委名单**：12 个职务卡片一览（在任 / 空缺），职责说明可编辑；「换届」一键调整职务并自动记录原任 → 新任；考核记录（日期 / 考核期 / 评分 / 评语）可增删。
- **主题班会 / 班级活动**：计划与记录均可增删改；班会记录含日期 / 类型 / 地点 / 主持人 / 参与情况，活动记录含地点 / 负责人 / 参与人数；班会计划可一键「转为已开展」；活动照片沿用 `assets/photos/` 本地占位，把实拍照片同名放入该文件夹即可展示（不存入数据库）。
- **设置中心**：顶栏「设置」提供班级信息修改、自动备份（每天 / 每周一次、保留份数、立即备份、备份并下载）、备份记录管理（恢复 / 下载 / 删除）、侧栏默认折叠开关，以及「清空数据重新初始化」。
- **内置使用手册**：顶栏「使用手册」打开页内参考手册，按模块讲解全部功能、搜索技巧与数据备份，带目录快速跳转。
- **新手引导**：首次进入自动弹出 5 步引导卡片（导航 / 工作卡片 / 顶栏工具 / 使用手册），高亮对应区域，可上一步 / 下一步 / 跳过；之后可在使用手册或「设置 → 界面」重新查看。
- **自动备份**：打开应用时自动检查，到达设定间隔即把全部数据快照存入本地 IndexedDB（保留最近 N 份），并提示「已自动备份」；也可手动「备份并下载」JSON 文件到电脑。
- **页面数据可编辑**：工作台各详情面板（考勤、纪律、作业、巡查、班会、家校、成长、活动）带「编辑」开关，可添加 / 删除记录，统计数据（如收缴率、迟到人数）自动重算；凡是填写学生姓名的输入框均带**联想选择**（支持汉字 / 拼音模糊）并**校验学生是否存在**，不存在会提示且不允许保存。
- 7 个导航模块（工作台 / 座次表 / 值日表 / 成绩分析 / 花名册 / 班委名单 / 课程表）已全部完成；家长联系信息直接复用花名册中的家长 / 电话字段。

## 数据说明与备份

- 数据保存在浏览器的 IndexedDB（数据库名 `homeroom-workbench`）中，改名字、调座位、增删学生后刷新页面依然保留。
- 首次打开会进入初始化向导：填老师姓名、选初始数据来源（CSV 花名册 / 示例班级 / 空白开始）。`js/data.js` 中的 48 名学生与示例记录仅在选择「示例班级数据」时写入。
- 若已有数据但缺少设置（旧版本升级），会自动补一份默认设置，不会清空现有数据。
- 换设备 / 清缓存前，请用顶栏「导出数据」下载 JSON 备份；新设备打开页面后点「导入数据」即可恢复。
- 活动照片目前是占位图，将同尺寸实拍照片以同名替换 `assets/photos/` 下文件即可。
